# CampusRide

CampusRide is a web application that helps students offer, find, and reserve affordable shared rides.

## Setup

1. Copy `.env.example` to `.env`.
2. Set `MONGODB_URI` to your MongoDB connection string.
3. Install dependencies with `npm install`.
4. Run `npm run dev` and open `http://localhost:3000`.

Visit `http://localhost:3000/api/health` to confirm the Express server is running.
